# Arcane Chunk Loaders

Pack-owned Forge 1.20.1 mod providing eight magic-gated, power-buffered chunk anchors. Each active anchor keeps its centered 3x3 chunk area fully ticking and exposes an operator registry/teleport command.

Build the runtime artifact with `gradle assemble`; the staged `build/libs/arcane_chunkloaders-0.1.0.jar` is the reobfuscated jar.
